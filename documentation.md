##### L'asymétrie est une mesure statistique utilisée pour décrire la forme d'une distribution de données. Elle permet d'identifier si la distribution est symétrique ou asymétrique, en s'intéressant à la répartition des données autour de la valeur centrale plutôt qu'à la seule distribution de fréquence. scipy.stats.skew(array, axis=0, bias=True)
##### Distribution basée sur la valeur d'asymétrie
- Asymétrie = 0 : La distribution est normale.
- Asymétrie > 0 : La distribution est davantage pondérée dans la queue gauche.
- Asymétrie < 0 : La distribution est davantage pondérée dans la queue droite
